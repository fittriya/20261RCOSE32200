# RAID Mapping Simulator

A simple web-based RAID simulator built with HTML, CSS and JavaScript.
This project helps users to understand how different implementation of RAID levels store data across multiple disks.

## Features
- RAID 0
- RAID 1
- RAID 4
- RAID 5

  ### Tools Used
  - HTML
  - CSS
  - JavaScript
 
  ### Main Purpose
  To help users to understand how RAID implementation works.
